🚀 TÀI LIỆU KẾT NỐI API BACKEND

Dành cho đội ngũ phát triển Frontend (Vercel & Localhost)

Base API URL: https://youth-union.onrender.com/api
1. Cấu hình biến môi trường trên Vercel

Trong file .env của dự án Frontend, các bạn điền dòng sau:

VITE_API_URL=https://youth-union.onrender.com/api
# Hoặc nếu dùng React Create-React-App:
REACT_APP_API_URL=https://youth-union.onrender.com/api
2. Danh Sách Endpoint Chi Tiết
GET /home
Trang Chủ (All-in-one)

Lấy 1 lần toàn bộ: Banners, 4 bài viết mới nhất, 6 CLB tiêu biểu, gương mặt tiêu biểu và thống kê.

https://youth-union.onrender.com/api/home
GET /activities
Hoạt Động & Tin Tức

Lấy danh sách bài viết. Hỗ trợ tìm kiếm: ?search=tuổi trẻ, phân trang: ?per_page=6.

https://youth-union.onrender.com/api/activities
GET /clubs
Câu Lạc Bộ (Đã nạp 7 CLB thật)

Lấy danh sách CLB kèm thể loại. Lọc theo thể loại: ?category_id=1. Danh sách thể loại: /club-categories.

https://youth-union.onrender.com/api/clubs
GET /outstanding-people
Gương Mặt Tiêu Biểu

Lấy danh sách tuyên dương. Lọc nhóm: ?role_group=DOAN_VIEN hoặc BI_THU_DOAN hoặc BGD.

https://youth-union.onrender.com/api/outstanding-people
GET /banners
Banner Slider

Lấy danh sách ảnh bìa slider đang hiển thị theo thứ tự.

https://youth-union.onrender.com/api/banners
POST /auth/login
Đăng Nhập Admin

Body JSON: {"email": "admin@youthunion.edu.vn", "password": "admin123"}

https://youth-union.onrender.com/api/auth/login
3. Code mẫu gọi API (JavaScript Fetch)
// Gọi API Trang Chủ
async function fetchHomeData() {
  const response = await fetch('https://youth-union.onrender.com/api/home');
  const result = await response.json();
  console.log('Dữ liệu Trang Chủ:', result.data);
  return result.data;
}
